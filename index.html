Two embodied nervous systems. One shared environment.

This runtime instantiates two independent agents from the same class of sensory-relay, lateral-inhibition, chemotactic, and escape-reflex motifs described in the male Drosophila central nervous system connectome. Each circuit is embodied in a six-legged, wing-bearing chassis and released into the same observation arena.

Neither agent is scripted. Foraging, avoidance, investigation, and resource contest emerge from independent initial conditions and stochastic spontaneous firing. The display is an observation instrument, not a game: there is no objective, score, or player-controlled agent.
